# Kamosu's own words in Dutch

Every Dutch phrase Kamosu writes, the server's and the screens', uses these
words, so the interface reads as one voice. No Dutch speaker approved this list.
A tester's reports correct it, and the next person to change a phrase sees here
what was chosen and why. Change a word here first, then in the phrases.

These are Kamosu's own terms from `GLOSSARY.md`. Kitchen words, such as `eetlepel`
or `naar smaak`, are in `src/words/nl.toml` and come from how Dutch recipes are
written.

| English | Dutch | Why this one |
| --- | --- | --- |
| Recipe | Recept | The only word in use. |
| Ingredients | Ingrediënten | Every Dutch recipe site heads its list this way. |
| Method | Bereiding | The heading Dutch recipes use most. `Werkwijze` is fair too, but reads like a lab report. |
| Step | Stap | The only word in use. |
| Cookbook | Kookboek | The only word in use. |
| Kitchen | Keuken | The only word in use. |
| Attempt | Kookbeurt | Chosen over `Poging`. An Attempt is simply a time you cooked it, and most go well. `Poging` says it may fail, which is the wrong thing to say to a cook on a good day. |
| Branch | Tak | Chosen over `Versietak` and `Vertakking`: short, and it holds the picture of one recipe growing two ways. |
| Version | Versie | The only word in use. |
| Thread | Geschiedenis | Chosen over `Draad`, which is no Dutch word for a history. It is also the word for History on a page. |
| Food | Voedingsmiddel | Chosen over `Product`, which is a thing in a shop, and `Ingrediënt`, which `GLOSSARY.md` keeps for a row in a recipe. Long, but it is seen in Settings and rarely. |
| Ingredient Line | Ingrediëntregel | Spelled with no hyphen, as Dutch writes a compound. |
| Reading | Lezing | Chosen over `Interpretatie`, which is long and sounds like an opinion. |
| Unit | Eenheid | The only word in use. |
| Tag | Label | Chosen over `Tag`, since `Label` is what Dutch interfaces say. |
| Sheet | Recept op papier | Chosen over `Blad`, which also means a leaf and a baking tray in a kitchen. `Afdruk` is short for the place a phrase has no room. |
| Share Link | Deellink | Written as one word, as Dutch writes a compound. |
| Bundle | Receptbestand | Chosen over `Bundel`, which is a book of poems. It is the file a recipe travels in. |
| Vault | Kluis | The word a Dutch password manager uses for the same idea. |
| Shopping List | Boodschappenlijst | The only word in use. |
| Yield | Opbrengst | On a recipe the number reads as `porties`. |
| Servings | Porties | The word Dutch recipe sites use, and the one Mealie ships. |
| Translation | Vertaling | The only word in use. |
| Language | Taal | The only word in use. |
| Reading Language | Leestaal | A new compound, and short. |
| Photograph | Foto | The only word in use. |
| Note | Notitie | Chosen over `Opmerking`, which sounds like a remark from someone else. |
| Tags heading | Labels | As Tag above. |
| Source | Bron | The only word in use. |
| Operator | Beheerder | The word Dutch software uses for this role. |
| Agent | Agent | Dutch has taken the word as it is. |
| Runner | Runner | Left in English, as Dutch software leaves a technical name. |
| Access Key | Toegangssleutel | The usual rendering. |
| Backup | Back-up | Written with a hyphen, as the Dutch spelling list has it. |
| Cook (a person) | Kok | The only word in use. |
| Co-author | Medeauteur | The only word in use. |
